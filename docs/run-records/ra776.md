# Native run source — ra776

Refs rickylabs/harness#776 and rickylabs/orchid#132.

The native read primitive supplies stable workspace/job coordinates, exact receipt keys and native session IDs directly from Orchid's existing run maps. Consumers establish liveness with current Herdr state; a native completion fence is distinct from an idle turn. The only methods are `run.lookup` and `run.subscribe`, documented in [the protocol](../native-run-read.md).
