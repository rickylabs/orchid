3. Ports: State-owned completion records, the existing native lookup/subscription socket, existing pinned-inode and kernel-peer helpers, and coordinator lifecycle calls.
4. Constants: existing frame, batch and connection bounds remain authoritative; the stale probe has a bounded timeout and fixed log reasons.
5. Commit slices: implementation and consumer regressions with full Go gates; then an independent supervisor documentation sign-off tied to the reviewed source commit.
6. Deferred scope: deployment, native admission reads, indexed negative identity, offline completion replay and unrelated coordinator decomposition. Root-only kernel proof requires the existing isolated CI lane.

## Lesson — 2026-11-01

Socket fixtures need executable short temporary storage and the intended file-creation mask. Mutation runners must serialize ownership of their source tree: a concurrent full suite can compile a temporary mutant and invalidate both verdicts. Prove exact restoration before the next gate, and distinguish a runtime regression failure from a compilation failure. Scan committed changes before pushing, because the repository leak scanner compares committed heads.
