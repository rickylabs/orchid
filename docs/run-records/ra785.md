# Native vendor startup and authentication: implementation evidence

Refs [harness#785](https://github.com/rickylabs/harness/issues/785) and
[atelier-cockpit#955](https://github.com/rickylabs/atelier-cockpit/issues/955). The contract is in
[native vendor startup and authentication](../native-vendor-auth.md). Upstream gaps are tracked in
[#141](https://github.com/rickylabs/orchid/issues/141).

## Source findings re-verified

At base `745875c`, the brief's audit findings from `8074c82` still held:

- AGY registration read the visible pane, matched English trust, sign-in and onboarding marker
  groups, and required `? for shortcuts`. A startup timeout was refined from the same screen.
- Supervision for every transport read the last 4 terminal lines and matched `Invalid bearer` or
  `Please run /login` before resyncing credentials and notifying.

## Discovery (installed vendors, no prompt that consumed quota)

- **AGY 1.4.12.** The binary embeds the official hooks documentation.
  - A scoped probe used a temporary settings directory and a temporary hooks file, in a private
    terminal session.
  - The CLI loads hooks from the gemini directory's `config/hooks.json`.
  - `SessionStart` did not fire at the idle composer, and nothing fired on the sign-in screen.
  - `--prompt-interactive` submitted its prompt even under an unanswered trust dialog. The turn
    failed upstream, and `Stop` reported `terminationReason: ERROR` with free text only.
  - The onboarding cache is a typed struct with field `onboardingComplete`.
  - The typed `auth_required` error appears only in the hidden ACP server mode.
- **Herdr 0.9.5.** The `antigravity_cli` integration hook (v4) reports session identity from
  `PreInvocation` only. The pane lifecycle comes from screen detection.
- **Claude Code 2.1.316.** The `StopFailure` input schema has `error` as a closed enum, which
  includes `authentication_failed`.
- **Codex 0.166.** Hooks have no failure event. The app-server `codexErrorInfo` includes
  `unauthorized`.

## Change

- `agy_startup.go` (new) owns AGY startup:
  - the typed onboarding fact;
  - an occupant-only registration check, with no screen read;
  - the named gaps.

  The screen markers and composer check are deleted, as are `visiblePromptScreen` and the 4-line
  `Host.read`, both dead with them. A startup timeout stays `startup_timeout`.
- `vendor_auth.go` (new) owns authentication for every transport:
  - Claude: a typed `StopFailure` receipt for the exact occupant and session.
  - Remote Control Codex: the newest failed turn with `codexErrorInfo: unauthorized`, through the
    shared bounded `newestNativeTurn` reader that capacity recovery also uses.
  - Every other transport: unknown, and never read.

  The effect is saved as `auth_signal` before it runs. It is one resync plus one notification,
  with no teardown.
- `herdr_lifecycle.go` / `vendor_lifecycle_event.go`: the existing managed hook now records
  Claude's closed failure enum, and a receipt with any other value never matches.
