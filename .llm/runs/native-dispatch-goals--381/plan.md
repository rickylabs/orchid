# Native dispatch goals — consolidated plan

Owner decisions: use authorized assignment max-tokens; absent stays unknown. Change Orchid dispatch integration, preserve divybot, and create one real proof dispatch. Dispatcher-only restart is authorized; the agent container must remain running. Harness #383 stays read-only and unchanged.

## Exact behavior

1. Validate the goal intent before launch. Native objective is the assignment's repository/issue reference plus its exact title, at most 4000 Unicode scalars and nonempty, no NUL. This value goes only to the private native goal service and already-private dispatcher state; never diagnostics or published evidence. No raw title is exported by evidence. A public GitHub title is already the assignment source; silently redacting the objective would change that assignment. This is not authorization to publish sensitive strings in fixtures or logs.
2. Budget grammar after the existing authorized /swarm parser: `^([0-9]+)(?:\.([0-9]+))?([kKmM]?)$`, at most 128 characters. Decimal, base 10; k/K=1000, m/M=1000000. Exact integer arithmetic only. Reject a fractional resulting token, signs, exponent notation, nonnumeric values, whitespace and results greater than 9007199254740991. Zero is numeric zero. Absent key gives null; explicitly empty key refuses. No token budget is derived from route identity, effort, quota or concurrency.
3. Existing registration, matrix receipt, prompt delivery remain. After prompt delivery succeeds, perform at most 40 exact-occupant reads separated by 250 ms, bounded by context. Read the official SessionStart `agent_session` report; do not derive an ID from pane/name/location. Validate response type agent_info, agent codex, originally registered name/pane/workspace and interactive-ready; source herdr:codex, agent codex, kind id and a bounded nonempty identity. Unsupported sources/kinds and different occupants refuse immediately. Missing reports retry within this bound, then remain unavailable. Reuse the already-established validated native_identity.go contract; it has no report-version field to negotiate. Installation version is evidence, not an invented protocol guard.
4. Persist NativeSessionID using the existing atomic 0600 binding writer under the private 0700 reservation, and only for a receipt still dispatched to that same Codex job. Never populate public parentRunId. Do not run a native goal write if prompt delivery or binding persistence failed.
5. Persist goal intent and opaque receipt key on the dispatcher job before prompt delivery, with Owned=false. After authoritative binding, connect to plain codex app-server via stdio on the assigned host. Identity/objective/budget never enter argv or logs. Initialize first. Allow only initialize, goal/get and goal/set, with bounded frames/context, correlation and exact response thread identity. Discard process stderr; diagnostics use closed reasons.
6. Creation state machine: goal/get must return null. Any non-null goal, including same-intent, refuses creation and is neither adopted nor replaced. Send exactly {threadId, objective, tokenBudget:number|null, status:active}. Validate the response and matching thread/goal/updated notification. Only then set Owned=true and persist. If remote creation succeeds but notification or local persistence fails, report inconclusive; do not retry creation, reset counters or claim ownership. On restart an unowned job never writes lifecycle state. Counters are never reconstructed. A future explicit reconciliation policy is outside this change.
7. Lifecycle writes require Owned=true, a validated private receipt bound to that issue and repository, and current native objective/budget equal to saved intent. Send exactly {threadId,status}; never resend objective or tokenBudget. Native get/set responses must carry valid counters and statuses; reject regressing counters or changed creation identity.
8. Event precedence: native complete is terminal. Explicit GitHub CLOSED/COMPLETED maps to complete from any other owned goal, including a limited goal. CLOSED/NOT_PLANNED or an actually reached configured dispatcher deadline maps to paused, except it does not replace native budgetLimited/usageLimited/complete. Herdr blocked maps to blocked only from active. OPEN, unreadable issue state, idle/done pane, merged PR or generic quota observations license no completion or limitation transition. Native runtime owns budgetLimited/usageLimited; the dispatcher preserves them rather than inventing exhaustion from a timeout or provider quota. Pre-thread launch refusals have no native goal to update and remain explicitly unavailable.
9. Native ancestry already exists in 133 measured thread_spawn records. Do not implement a replacement spawn path or synthesize parent/depth. The per-issue telemetry reader already consumes native parent provenance; binding the root is the needed write-side join. The flattened thread/list projection discrepancy is recorded separately as a read-side finding, without changing #383 in this PR.

## Risk controls

Wrong target: exact official report plus private receipt checks. Budget escalation: authorized grammar and exact arithmetic. Counter resets: status-only writes and no adoption after uncertain creation. False completion: explicit lifecycle event mapping. Leakage: stdin-only identities and closed logs, full-diff scan. Unsupported runtime: inconclusive, never guessed evidence.
