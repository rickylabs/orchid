4. Durable private exact-scope ledger with refusal-dominant equal times, strictly later same-scope successes, including tombstones. Both refusal and success timestamps come from the SAME verified native event clock; never stamp refusals on local receipt while stamping successes on native clocks. Private ingestion sequence and native event fingerprint prevent replay/reordered events clearing later refusals. Cross-clock success without proven ordering is ignored for clearance; source times are preserved. Atomic synced replacement, same UID0600, no symlink traversal. Retain on source failure and restart. A success tombstone means a verified successful inference in an exact scope (Cockpit542 contract), not configuration removal. Never evict active refusal. Reserve ledger capacity against the finite configured route/account/key inventory before dispatch (at most512 scopes including explicit global scopes, reserving two rows per scope under Owner549 for blocking/success and informational rate evidence); reject configurations that exceed remaining capacity including retained retired scopes. Success tombstones stay in the public bounded ledger while their configured scope is active. A private explicit compaction operation may archive ONLY inactive succeeded scopes and install permanent private retired-scope replay fences; a retired scope cannot accept events or be rebound without retaining its archived success watermark. No unlimited model churn or automatic eviction. Overflow/storage failure fences dispatch and retains previous ledger/snapshot rather than truncating history. Separate ledger survives public source deletion. Future native outcomes whose identity is unproven stay unknown.
5. Strong bound OpenCode export already establishes prompt, route, session, clocks, parent and before/after occupant fences. Add only typed closed quota/payment/rate outcomes after all fences. Error text is never public. Verified completed answer supplies success timestamp. Extend native boundaries only where their structured bound event proves inference; do not treat CLI exit, metadata or PR state as success. Do not add operator receipt import or metadata clearance. Unsupported native sources report unknown until an adapter has proven structured inference evidence. Native-bound and inference-probe are private provenance kinds, compatible with the public closed provider-run/inference-probe vocabulary.

Charter section11 forbids settings/activation without GO; it does not forbid implementing this authorized bug fix behind existing release deployment controls. No default-off flag that silently preserves the bug. Warning90 constant is advisory only and never feeds admission. Governor and subscription availability depend on physical capacity, not percent/missing/stale meters, burn estimates or ceilings. Paid budget decisions cease vetoing/fallback and cease emission as unavailable; no invented paid-eligibility claim. Existing authentication/grants/discovery/provider pools and owner exact-choice semantics survive.
